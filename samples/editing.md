# Aropyt 编辑体验

点击代码内容即可编辑。使用方向键在代码行之间移动，按 Tab 缩进，按 Command+Z 撤销。

## Java 代码

```java
public class Demo {
    public static void main(String[] args) {
        System.out.println("Hello, Aropyt!");
    }
}
```

代码框右下角可以更改语言。源码模式中可以编辑完整的 Markdown 围栏。

## Mermaid 流程图

```mermaid
graph LR
    A[Markdown] --> B[编辑]
    B --> C[预览]
```

点击图形展开代码框，下方图形实时更新；移出后收起代码框。
