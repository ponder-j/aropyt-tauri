# Aropyt 使用指南

本文介绍当前可用操作。支持边界与尚未对齐的行为见[功能状态与 Typora 差异](typora-parity.md)；构建方式见[项目首页](../README.md)。

## 快速开始

打开 Markdown 文件，或新建文档后直接输入。代码块保持代码框，右下角可以修改语言，候选带有语言图标；Enter 确认并留在输入区，Tab 返回代码。点击 Mermaid 后，上方展开代码框，下方保留实时图形预览；光标离开后收起代码框。

以下快捷键以 macOS 为例。保存：Command+S；源码模式：Command+/；查找：Command+F；替换：Command+H。Windows/Linux 的对应绑定使用 Ctrl；当前回归检查已在 Windows x64、macOS arm64 和 Docker Linux x64 完成。构建和平台边界见[构建与发布](releasing.md)。

## Markdown

Enter 创建新段落，Shift+Enter 在当前段落或列表项内换行。段落开头按 Backspace 可与前一段合并。

使用 `# 标题` 创建标题。粗体为 `**文字**`，斜体为 `*文字*`，链接为 `[名称](地址)`，图片为 `![说明](地址)`。段落菜单提供表格、代码、公式、任务列表、脚注和目录。简单引用及列表可直接编辑正文。点击行内公式可编辑 TeX 并查看浮动预览；点击独立图片会展开图片 Markdown，预览继续保留。

正文右键菜单使用四个剪贴板图标及两行格式按钮，按内容提供标题、插入、图片、代码或表格子菜单。右键保留当前选区；命令执行前恢复选区。方向键在菜单内移动，→ 展开子菜单、← 返回，Enter 执行，Escape 关闭。源码模式仅显示剪切、复制、粘贴。

代码源码区提供复制正文、调整选中内容/整个代码块缩进；局部缩进会参考整个代码块的层级，框外选区不可使用该命令；公式或 Mermaid 的渲染区不显示代码命令。图形可复制为图片或另存为 SVG/PNG，公式还可复制 TeX、MathML 或供 Word 粘贴的公式 HTML。

点击标题时保留排版；在标题文字开头按 Backspace 可以取消标题格式。源码模式可以直接修改 Markdown 标记。

## 表格

输入 `| 表头一 | 表头二 |` 后按 Enter 可以创建表格并进入第一格。直接在单元格内编辑。光标进入加粗、斜体、代码或链接时，只展开该段的 Markdown 标记，相邻格式继续显示。点击单元格公式可编辑 TeX 并查看浮动预览，离开后恢复图形。Tab 移到下一格，在末格按 Tab 新增一行；Shift+Tab 返回上一格。Enter 移到下一行，Shift+Enter 在单元格内换行。Command+Enter 在当前行下方插行，Command+Shift+Backspace 删除当前行。表格上方工具栏提供对齐，左侧按钮打开尺寸网格；可输入行列数建立更大表格。右键菜单及段落菜单提供行列增删；右键“表格”子菜单还支持行列移动（Alt+方向键）、复制和整理；也可以粘贴电子表格中的多格内容。修改进入文档的统一撤销历史。

## 选择与删除

“编辑 → 选择”提供段落或块、当前行或句、格式文本及词的选择。“编辑 → 删除范围”提供对应的删除动作。正文按句子处理，代码框按代码行处理，表格按当前整行处理；Command+Option+Shift+L 删除当前行或句。

选择格式文本只选其正文；删除格式文本同时去掉格式标记。修改可以撤销。

## 导入与导出

HTML、PDF 和 PNG 使用应用内置引擎，等待图形和公式完成后导出整份文档。导出与当前选区、源码模式、滚动位置无关。

Word、OpenOffice、Epub、LaTeX 及其他文档格式使用 Pandoc。在偏好设置的导出页面配置 Pandoc 可执行文件路径；常见安装路径会自动识别。导入也使用 Pandoc。

导出的 Word 表格和公式保留文档结构，Mermaid 转为图片；HTML 图片也会嵌入并保留缩放后的尺寸。LaTeX 等文本格式引用的图形会保存在导出文件旁的 assets 文件夹；分享时需要一同提供。

## 图片

通过“格式 → 图像”插入网络地址或选择本地图片。偏好设置可以选择复制到文档目录、assets 文件夹、每篇文档的独立 assets 文件夹或自定义目录。

右键独立图片可打开位置、复制/移动文件、上传图片、复制图片内容，选择 25%、33%、50%、67%、80%、100%、150%、200% 缩放，或转换 Markdown/HTML 语法。删除本地图片会先确认并移到废纸篓；在线图片只从文档移除。缩放使用 HTML 的 zoom 属性；HTML 图片也支持 width 和 height。点击 HTML 图片可编辑整段标签，预览继续保留；转换回 Markdown 会去掉尺寸属性。

上传需要你配置自己的图床程序。PicGo/PicList 桌面程序可以使用本地 HTTP 服务；命令行方式会把图片路径作为参数传给配置的命令，并读取输出中的 HTTP 地址。

## 恢复

编辑时的草稿保存在应用用户数据目录。使用“帮助 → 文档恢复”选择草稿恢复。恢复后请检查内容并保存。

## 主题

在主题菜单选择主题。选择“打开主题文件夹”可以放入自己的 CSS，再重新打开应用。主题控制字体、颜色和正文布局，功能配置放在偏好设置中。

## 字数统计与设置搜索

底栏左侧提供侧栏和源代码模式按钮，右侧常显字数；鼠标移到右侧统计区域时出现 A✓ 拼写检查按钮和统计箭头。点击字数或“视图 → 字数统计窗口”展开带标题的面板，依次显示阅读时间、行数、词数和字符数，点击条目更改默认单位。选中文字后，底栏显示“选中 / 全部”，展开面板继续显示整篇文稿。外观偏好可设置是否显示统计及阅读速度（1–999 词/分钟，默认 382，另提供 120、240 预设）。

词数采用对照程序的字符区间与标点规则，计入代码、语言名称、链接和图片路径中的文字。例如“这是中文，测试。”为 7 词，“한국어 텍스트”为 2 词。字符数为原始 Markdown 的 UTF-16 长度，包含空格、换行和格式标记；行数为换行符数量加一，空文档为 1 行。阅读时间按设置的词数/分钟四舍五入，结果为 0 时显示“≤ 1 分钟”。

偏好设置中的搜索会查找设置内容并定位到对应页面，高亮匹配的设置组。按 Escape 清除搜索。

## 拼写检查

点击底栏 A✓ 打开语言菜单，可选择自动检测、不使用检查或 36 种语言选项（中文、日文按参考规则使用英语词典）。上方输入框按语言名称或代码筛选，方向键移动、Enter 选择、Escape 关闭。该选择作用于当前文稿；底部“全局设置…”打开默认语言及代码/链接检查设置。自动检测使用文档开头至多四个段落或标题的纯文本，CLD2 结果不可靠时回退到系统语言；中文、日文和印地语使用英语词典检查夹杂的英文。

错词使用系统原生波浪线，右键最多显示六个 Hunspell 建议，可学习拼写或对已学习的词取消学习。用户词典按语言保存为配置目录下的 `user-dict.json`，旧的单词列表会自动迁移。默认跳过代码与链接，不上传正文或单词。

展开侧栏后，左下角按钮移到编辑区左边缘，侧栏图标变为“<”。源码模式在该位置只显示深色 `</>` 按钮，点击“退出源代码模式”恢复编辑预览与两个按钮。

## 与 Typora 对照

Aropyt 尚未与 Typora 完全一致。当前实现、已确认差异、尚未验证范围及验证命令统一维护在[功能状态与 Typora 差异](typora-parity.md)。隐私与联网行为见[隐私说明](privacy.md)，资源来源见[第三方组件](credits.md)。
