# Aropyt 隐私说明

文档、偏好设置、恢复草稿、主题、词典和用户学习的单词均存储在本机。应用没有遥测、账户、商业授权或自动更新服务。

拼写检查默认关闭，词典默认不安装。用户选择下载时，只向清单中固定的 jsDelivr / GitHub 原始文件地址请求该语言词典；检查和语言检测都在本机进行，文稿内容不上传。也可以完全离线导入本地 Hunspell 词典。

文稿中的网络图片会向对应服务器请求资源。使用图片上传功能时，选定图片交给用户配置的 PicGo、PicList 或上传命令。导入和 Pandoc 导出在本机执行，外部链接由默认浏览器打开。

首次启动将旧版数据复制到独立的新目录，原数据保留。自动化测试使用隔离目录。
