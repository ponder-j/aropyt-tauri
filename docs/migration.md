# Tauri 2 迁移核对

本项目以原 Aropyt 的完整工作区为基线迁移。原项目修订记录在 [source-baseline.json](source-baseline.json)。编辑器和界面继续使用原实现；窗口、系统接口与持久化由 Rust / Tauri 2 提供。

## 功能对应

| 原有功能 | Tauri 实现与验证入口 |
| --- | --- |
| 即时编辑、源码模式、标题与行内标记、格式命令 | 保留 CodeMirror / Markdown 实现；原 67 项编辑回归在系统 WebView 中执行。 |
| 代码框、语言、补全、语法高亮、Mermaid | 保留原实现；保留图表编辑时下方预览、语言切换及撤销。 |
| 行内公式、块公式、表格内公式 | 保留 MathJax 和局部 TeX 编辑；导出保留 SVG，并隐藏重复的辅助 MathML 视觉内容。 |
| 表格导航、行列操作、尺寸、粘贴、输入法、撤销 | 保留原实现；回归覆盖 TSV、IME 合成事件、边界及邻接内容。 |
| 文件树、大纲、快速打开、查找替换、焦点、打字机 | 保留原前端；Rust 提供目录、搜索和文件操作。 |
| 文件编码、保存规则、改名、移动、废纸篓 | Rust 实现；真实 UTF-16 / UTF-8 读写、尾空白、末尾换行与 CRLF 检查。 |
| 草稿、自动保存、最近文件、多窗口、全部保存 | 保留前端业务流程；Rust 提供草稿及窗口状态；取消操作不丢弃未保存内容。 |
| macOS 原生标签页、窗口菜单、全屏、置顶 | Tauri 窗口与 AppKit 标签分组；保留原菜单模型和语言。 |
| 默认及自定义快捷键 | 原前端键盘处理保留。属于编辑器的菜单快捷键不注册为全局原生快捷键，避免抢走表格或自定义绑定的输入。 |
| 统计、拼写语言面板、动态右键菜单 | 保留原控制器和菜单；本地 Hunspell WASM + CLD2；系统 WebView 中补充拼写下划线。 |
| 主题、字体、偏好设置 | 保留全部内置主题、字体和偏好项；本地 CSS 的图片和字体在预览及导出中内嵌。 |
| 图片、上传器、富文本剪贴板、媒体另存 | Rust / 系统剪贴板及原图片业务规则；支持 PicGo/PicList 和用户配置命令。 |
| HTML、PDF、PNG、打印 | 使用完整静态导出文档；系统 WebView 渲染。macOS 使用异步原生分页打印，窗口及资源在主线程释放。 |
| Word、ODT、Epub、LaTeX 等九种转换及导入 | Pandoc 接口迁至 Rust；验证实际文件、Word 表格/可编辑公式/图表、HTML 图片尺寸及 LaTeX 持续资源。 |
| 旧版配置、主题、恢复草稿、用户词典 | 首次启动复制到独立数据目录，保留旧目录；不覆盖目标中已有文件。 |

渲染器中 23 个文件逐字节保留。修改的五个文件仅涉及系统图片 URL、Tauri 拖放路径、退出确认接口、可选词典入口及独立导出文档样式。新增的平台桥负责系统 WebView 差异，未重新设计界面。

## 经用户确认的调整

离线词典用于拼写检查，不是语法检查。默认关闭、不安装词典；用户可以在开启语言时确认下载，也可以在偏好设置下载或导入本地 `.aff` / `.dic`。全部原语言模式仍保留。下载版本及 SHA-256 固定，词典检查、语言检测和学习单词均留在本机。

原应用中的 Electron / Chromium / Node.js 运行时不随新版打包。Pandoc 继续作为可选外部依赖。

## 验证范围

按用户要求仅验证 ARM，不检查 x64。macOS Apple Silicon 的 84 项真实 WebView 检查已通过；另外通过路径/URL 回归、13 组统计参考数据及类型检查。原 Electron 检查脚本归档在 `tests/electron-reference/`，不计入新版验证。

覆盖实际文件、剪贴板、草稿、取消保存、词典下载与校验、离线检查、建议和学习、CLD2 检测、九种 Pandoc 格式、原生 PDF / PNG、多窗口及标签页。长文档 PDF 已核对分页、A4 页面和尾部文本，导出保持可选择文本与矢量公式/图表。

macOS APP / DMG 使用本机 ARM 原生构建。默认 APP 约 20 MiB、DMG 约 15 MiB；本机旧版 Electron APP 约 400 MiB，APP 体积减少约 95%。词典不在安装包内。

Linux ARM（aarch64，Docker / Xvfb / WebKitGTK）同样通过完整 84 项检查；修复了旧版 WebKitGTK 的缩放几何坐标差异，并让独立导出窗口在映射后完成原生截图。Windows 保留平台适配和构建入口，本轮不做 x64 检查，也不把未运行的平台记作已验证。原项目的 Typora 差异仍见 [功能细节](typora-parity.md)。
