# 功能状态与 Typora 差异

> 本文以原项目的差异记录为基线，并持续记录 Tauri 版的实际对照。文末的 Electron 历史验证记录不代表 Tauri 验证；迁移和平台检查范围见 [迁移核对](migration.md)。

更新日期：2026-10-22。本文描述当前源码已实现的行为；Aropyt 尚未 1:1 复刻 Typora。“已实现”“已确认差异”和“尚未验证”分别列出，避免把菜单存在或设置能够保存当作功能已完成。

## 对照基准

- 编辑交互主要对照本机 **macOS Typora 1.9.4** 的实际操作及保存后的 Markdown。
- 底栏、统计与拼写面板、正文右键菜单同时采用用户提供的 **Windows Typora 1.9.5 / 新版截图及分析文档**。这些界面与本机 Mac 版不同：Aropyt 的正文菜单采用参考中的 DOM 图标行，本机 Mac Typora 使用系统菜单；底栏也采用用户指定的新版布局。
- 官方帮助用于发现检查项，不作为本机行为已经一致的证据。不同平台和版本的结果不能直接互相替代。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 标题与段落 | ATX 标题隐藏 `#`，点击保持字号和间距，开头 Backspace 取消格式；Setext 下划线只作用于紧邻的上一行，与本机 Typora 一致，编辑区、目录及导出共用同一范围。Enter 创建段落，Shift+Enter 保留段内换行；段落合并、额外空段落及撤销有检查。 |
| 行内编辑 | 常见段落中的加粗、斜体、行内代码和链接只展开光标所在片段；保留相邻格式、嵌套及转义。支持行、句、格式文本和词的选择/删除；多行缩进选区结束于下一行开头时，不改变未选中的下一行。 |
| 代码框 | 围栏隐藏，正文直接编辑；支持方向键、缩进、空框、未闭合围栏、代码高亮、行号及撤销。右下角语言候选含字体图标和别名，聚焦不挤动下方排版，输入与正文事件隔离。 |
| Mermaid | 点击图形展开上方代码框，下方保留实时图形；有效修改后更新图形，离开后收起代码框。语言外框包含在预览区域内；导出等待 SVG 渲染完成。 |
| 数学 | 行内和表格公式点击后选中 TeX 并显示浮动预览，离开后恢复图形，保留邻近格式。支持公式块及 `math` 围栏、TeX/MathML 复制和 SVG/PNG 保存。 |
| 列表与任务 | 简单引用、列表和嵌套文字项保持结构；Enter 续写编号、引用或未完成任务；同一文字行内选中文字后回车也保留列表或引用前缀，正反向选区一致，支持 Tab 分隔的列表标记和任务状态重置。空项回车创建真正分隔的新段落，保留父列表或父引用的层级。非空列表项开头 Backspace 将正文并入前同级或父项的续段；首项取消标记时提升其子项，保留后续同级及必要段落空行；空行保持可编辑，不使整个列表展开为源码。Tab/Shift+Tab 在列表正文中整体调整当前项、子项及续行，沿用相邻项的缩进；没有前项的首项 Tab 保持字面制表符。嵌套引用开头退格只退出一层。退出后的父列表段落保持原生文字编辑，缩进及退出操作可单步撤销。Shift+Enter 创建不带新圆点的续行；任务勾选可以撤销。 |
| 表格 | 输入表头后 Enter 建表；单元格直接编辑，局部展开行内格式、公式和普通图片。Markdown、带尺寸的 HTML 图片及引用式图片保留预览，点击图片只选中其替代文字或 HTML 语法；修改与表格撤销共用历史；显式单元格换行不再使图片展开为整格源码。表格图片沿用正文图片右键菜单，右键保留原选区，缩放、语法转换和文件转移只更新目标图片，保留原表格空格及对齐；过期的异步结果不会覆盖已经改变的源码范围。图片属性、代码、链接和 TeX 阻止系统自动替换损坏源码，保留手动输入、输入法及普通文字的纠正。支持 Tab/Enter 导航、尺寸网格与数字输入、行列增删/移动、对齐、复制、整理、TSV 粘贴和统一撤销。 |
| 独立图片 | 编辑 Markdown 或 HTML 时保留预览；加载失败时显示可编辑源文。支持尺寸属性、25/33/50/67/80/100/150/200% 缩放、语法转换、打开位置、复制/移动文件、复制图片内容及上传入口。 |
| 混排图片与引用 | 普通段落中的 Markdown / HTML 图片保留自然尺寸或显式尺寸；点击后局部展开语法并保留预览。引用式图片使用整篇文稿的定义，定义修改会更新正文和表格中的预览，原引用语法不自动改写。正文混排图片沿用图片右键操作。 |
| 脚注 | 正文和普通表格单元格中的引用以标签上标显示，点击局部展开并选中标签，保留相邻粗体、图片及公式；代码和 TeX 中的脚注语法保持字面文字。悬停显示黑底正文预览，保留强调、代码、链接、图片及公式，使用整篇文稿的引用定义；定义修改与撤销会刷新已打开的预览。浮层不抢选区，离开、点击编辑、Esc、滚动或切换源码模式会关闭，并适配应用缩放及视口边界。定义留在原位置，正文可以直接编辑并保留行内格式；返回箭头可以聚焦表格中的引用单元格。 |
| 正文右键菜单 | 剪贴板四图标、两行格式按钮、动态块类型、插入及内容专用子菜单；右键保留选区，支持子菜单翻转、视口限制、键盘导航与禁用状态。代码命令只在源码区出现；源码模式仅显示剪切/复制/粘贴。 |
| 底栏与统计 | 按新版参考显示侧栏/源码按钮、悬停出现的 A✓、可点击统计面板。拼写按钮采用现有字体中的完整 A✓ 图标，禁用时保留勾号并在提示中标明状态；收起侧栏时圆圈按钮悬停显示中心实心点。展开侧栏后按钮跟随编辑区，源码模式在侧栏按钮位置显示带图标和“退出源代码模式”文字的灰底按钮；点击退出后恢复两个图标按钮。统计原始 Markdown，包含代码、语言及地址；显示阅读时间、源文行数、UTF-16 字符数和选中/全部。 |
| 拼写 | 本地 Hunspell WASM 与 CLD2，36 个语言选项，可搜索、自动检测、关闭或按文稿选择语言；最多六个建议，按语言保存学习/取消学习。默认关闭且不安装词典，后续按需下载或导入；默认跳过代码和链接。 |
| 查找替换 | 顶部横向查找栏，替换行按模式展开；包含大小写、整词、正则、前后导航和当前/总命中数。正文及表格同时高亮各处命中，以深色标记当前项；图片地址命中时局部展开语法并保留预览，关闭后可直接编辑匹配的单元格选区。连续输入和导航保留查找栏焦点；单项替换前往下一处，编辑与撤销同步更新命中，全部替换统一撤销。正则替换支持编号/命名捕获组、完整匹配及美元转义，保留前后文条件；零宽匹配按 Unicode 字符前进。支持中文文案及 Esc 关闭。查找和侧栏输入框的全选只选择查询文字；查找框内撤销/重做保留查询、返回正文并操作文稿历史，与本机 Typora 的实测一致。 macOS 保留 Control-A 的系统行为，输入法组合期间不触发这些新增快捷键。 |
| 文件与视图 | 保存/另存为/移动、编码检测和换行符、自动草稿与恢复、未保存确认、文件树/平铺文件列表、大纲、查找替换、整词搜索、快速打开、焦点/打字机模式及 macOS 原生标签页。侧栏展开/收起以 220 毫秒过渡同步移动正文与底栏，内容保持原宽度；快速反向切换延续当前进度，拖动宽度即时响应，尊重系统减少动态效果设置，恢复启动状态不播放动画。 |
| 侧栏工具栏 | 文件/搜索视图底部恢复加号、当前目录、更多操作及列表/树切换。鼠标进入侧栏后以 180 毫秒渐显并轻移，离开后渐隐；工具栏的键盘焦点和已打开菜单也保持可访问，搜索框或文件项焦点不会单独使工具栏常驻，尊重减少动态效果设置。菜单接入新建、搜索、文件管理器、打开目录、刷新、最近目录，以及自然顺序/名称/修改时间和升降序排序。新建在列表内输入文件名，保留未保存确认，拒绝路径穿越和覆盖；刷新保留输入内容与焦点。列表显示扩展名和两行真实摘要，搜索输入框随侧栏宽度保留两侧内边距。 |
| 侧栏查找入口 | 按指定的 Windows 截图，初始显示“文件 / 大纲”，文件标签选中且搜索框折叠；全新配置默认显示含摘要的文档列表，保留已有的树视图偏好。在标签栏向下滚动或在内容顶部下拉会以 180 毫秒过渡展开“文件 / 查找”和输入框；文件列表的普通向下滚动保持原行为。点击文件或按 Esc 收起查找并恢复大纲标签；菜单搜索入口仍可直接进入。悬停搜索框显示区分大小写、整个单词及正则选项，键盘聚焦选项也会显示；三个开关独立于文稿查找，直接作用于本地文件内容搜索。保留查询与选项，忽略过期的异步结果；支持键盘标签切换、窄侧栏和减少动态效果。该入口遵循用户指定的 Windows 样式，区别于本机 macOS Typora 的独立搜索图标，参见[官方文件管理说明](https://support.typora.io/File-Management/)。 |
| 原生菜单快捷键 | F8/F9、搜索、源码模式、撤销、格式及其他快捷键使用系统菜单的独立快捷键栏，不再拼入标题；对齐和文字颜色由系统绘制。macOS 仅在菜单展开期间显示编辑器负责的 key equivalent，关闭后清除，避免抢走正文、表格和输入框按键；GTK 使用不注册按键的 AccelLabel；macOS 重做提示使用原生 Command-Shift-Z。 |
| 主题与偏好 | 内置主题与自定义 CSS，补齐主题所需的 16 个字体文件；支持代码/列表缩进、智能标点、图像、图表、数学、导出、统计等设置，偏好可跨栏目搜索。七个设置页、主界面、原生菜单、右键菜单、表格/代码控件、弹窗、通知、恢复和字典选项支持完整中英文文案；在“通用 → 语言”选择简体中文、英语或跟随系统，即时同步各窗口。切换保留文稿、选区、撤销历史和设置页尚未提交的输入；已打开的应用内弹窗原地翻译。Markdown、LaTeX、品牌、代码语言和用户文件内容保持原文。 |

## 已确认未完全一致

| 范围 | 差异或限制 |
| --- | --- |
| 复杂内容的局部编辑 | 复杂 HTML、部分块级公式及复杂嵌套列表仍使用块级源文路径。表格中的复杂 HTML、复杂多行混排媒体及多行脚注未完整对齐。 |
| 界面与平台集成 | 右键菜单和底栏采用上述 Windows/新版参考，不等同于 Mac Typora 的原生菜单和标题栏统计。代码语言候选集合、高亮、主题留白和字体细节仍有差异。应用自有界面文案支持中英文；系统文件选择器、打印面板及系统服务项目遵循操作系统语言，外部工具的原始诊断保留原文并提供本地化提示。 |
| 代码格式化 | 当前提供基础缩进调整，局部缩进会考虑整个代码块的层级；这不是覆盖每种语言的完整格式化器。 |
| 拼写与纠正 | 使用公开词典，未使用 Typora 的私有词典 fork；判词和建议顺序不能保证完全相同。语法纠正未复刻。中文、日文等语言模式按参考规则使用英语词典检查夹杂英文。 |
| 图片与图表 | 图片拖动缩放、复杂混排媒体、表格边缘拖动重排及多种旧图表语法的兼容尚未完成。PicGo/PicList 和命令行上传入口已接入；iPic/uPic/Picsee 没有同等专用集成。 |
| 系统功能 | Typora 的原生文件版本历史、分享、最近文稿系统集成，以及系统替换、朗读、听写等完整菜单未全部实现。 |
| 发行 | macOS ARM 提供 APP / DMG，Linux ARM 提供 DEB / AppImage；既有 CI 发行流程与本轮 ARM 本机验证范围分别见[构建与发布](releasing.md)。正式签名及公证需要配置证书，尚无在线更新服务。 |

段落格式操作的选区若恰好结束于下一行开头，仅处理实际选中的行；标题、引用、列表与任务状态命令均遵循此边界，反向选区一致，保留单步撤销。此行为与本机 Typora 对首行及换行符选区的实测一致。

## 尚未完整验证

这些项目不能标为“一致”，也不能仅因缺少检查就认定全部未实现：

- 复杂跨块选区与删除、完整嵌套列表项，以及所有语言的句子/词边界。
- 所有输入法、键盘布局和辅助功能选区；已有 Blink 到 CodeMirror 的选区同步检查，但未覆盖所有路径。
- 全屏、原生标签页、多屏、所有主题组合下的底栏、统计、菜单及窗口恢复。
- 大型文档性能、磁盘外部修改与冲突处理、全部数学扩展包、公式引用和连续编号。
- 跨块或跨单元格的复杂搜索，以及空代码框、全部隐藏结构标记和零宽命中的视觉定位组合。
- 真实第三方图床服务、视频和展开 emoji 的右键菜单分支；后两者已接入条件分支，尚无本机 Typora 实拍对照。
- GitHub Actions 发行工作流的实际执行、所有平台完整的安装/卸载及桌面集成验收，以及所有导出格式的逐页排版对照。Linux 已验证 Debian 12/X11 容器环境，Wayland 和其他发行版仍需检查。

## 导入导出

| 格式 | 已验证范围 | 验证边界 |
| --- | --- | --- |
| HTML / 无主题 HTML | 从完整文档生成，嵌入图片、字体、公式及 SVG 图形；重开不依赖文档脚本，保留 HTML 图片缩放尺寸。 | 不保证所有自定义主题及复杂 HTML 一致。 |
| PDF / PNG | 使用完成渲染的同一份文档；覆盖正在编辑的 Mermaid、源码模式、多个图形、公式、图片、文末及长图。PDF 曾渲染目视检查。 | 未逐像素对照全部文稿及纸张组合。 |
| 打印 | 共用完整导出文档，检查打印准备结果。 | 未向物理打印机发送任务。 |
| Word / ODT / Epub | 使用 Pandoc，检查真实归档结构。Word 包含原生表格、可编辑公式、嵌入图片、Mermaid 及 HTML 图片尺寸。 | 并非全部经过对应阅读器逐页目视检查。 |
| LaTeX / RTF / MediaWiki / rst / Textile / OPML | 生成实际文件；LaTeX 另外核对公式及持续可用的图形资源。 | 其余格式主要检查输出非空，不代表完整排版一致。文本格式的媒体资源需一同分享。 |
| Word 导入 | 真实 DOCX 经 Pandoc 转回 Markdown，核对正文及公式。 | 复杂 Office 文档结构未穷举。 |

Pandoc 是额外依赖，需在本机安装或配置路径。格式自身可表达的结构不同，例如 OPML 面向大纲；成功导出不等于与 Typora 排版相同。

## 验证范围

### Tauri 版本机 computer use 对照（2026-10-22 至 2026-10-23）

实际启动本机 macOS Typora 1.9.4 与 Aropyt Tauri，使用相同内容、GitHub 主题和临时文稿，Tauri 使用隔离配置。逐项观察代码框聚焦与语言入口、表格聚焦与尺寸网格、普通/引用/HTML 图片、脚注、Setext、数学、Mermaid 及查找栏的显示；对混排图片执行真实点击、文字输入、保存与撤销，核对落盘 Markdown 只改变选中的替代文字。查找栏额外执行连续输入、切换替换模式及 Esc 关闭，确认查询焦点和文稿内容。

本轮修复上述媒体、引用、脚注、Setext 和查找栏差异，并扩展编辑回归，检查尺寸、引用更新、局部选区、失败图片、代码/TeX 中的字面语法、表格媒体、系统自动替换的源码保护和撤销；查找功能回归覆盖模式切换、焦点、计数、全部命中与媒体展开、单元格换行/转义范围、恢复编辑选区、替换及撤销、捕获组/前后文条件与 Unicode 零宽匹配。额外实机对照了 Typora 的全部命中高亮、图片源码展开、关闭查找后的选区、`$1` 捕获组替换、表格图片菜单与缩放，以及表格脚注标签的局部修改。表格图片检查覆盖预览/源码定位、转义竖线与换行、引用式图片、HTML 回退、保留列空格、空单元格删除及撤销；实际右键菜单还验证了复制/移动到资源目录后的文件内容和引用更新，并模拟 WebKit 在右键按下与菜单打开之间切换焦点，检查重绘后的格式选区恢复；表格脚注检查覆盖局部选区、字面代码/TeX 和返回引用。

根据[官方脚注说明](https://support.typora.io/Markdown-Reference/#footnotes)补齐悬停正文预览，新增四项编辑回归与一项真实渲染检查，覆盖正文/表格、整篇引用上下文、定义修改与撤销、缺失定义、被动 HTML、浮层关闭、缩放与边界，以及实际 SVG 公式、本地图片、HTML 图片尺寸和无浮层污染的导出。复杂多行脚注在本机 Typora 的解析方式与当前 Markdown 引擎仍有差异，不据此宣称完全一致。

底栏、统计/拼写面板及 DOM 图标右键菜单继续采用指定的 Windows/新版参考，源码模式按钮按用户截图显示“退出源代码模式”。可选词典保持默认不安装。

根据用户补充截图及本机 Typora 实际点击，补齐侧栏底部目录操作、列表摘要、可伸缩搜索框，以及禁用拼写图标和圆圈悬停状态。新增三项功能回归，覆盖菜单与键盘退出、真实排序/目录切换/刷新、宽窄布局、新建取消与重名保护。隔离测试实例使用独立配置并绕开普通单实例转发，避免临时文稿进入正在运行的日常编辑窗口。

最终实机新建检查还修正了长列表中输入框被浮动工具栏遮挡的问题：标签栏不再被内容压缩，滚动区域为底部工具栏保留可见空间。该最终布局在 macOS ARM 打包版的 25 项功能检查和 Linux ARM 的 109 项离线回归中通过；另采样检查侧栏动画、工具栏透明度过渡、宽窄搜索框、中心实心点及减少动态效果规则。悬停样式采样使用隔离 WebView 中临时替换的测试选择器，不作为原生鼠标移动的证据。

原生菜单快捷键修正增加了读取实际系统菜单的检查，覆盖 F8/F9、Backspace 和标点键提示、全部菜单标题，以及菜单关闭后不注册编辑器快捷键。macOS ARM 打包版通过 26 项离线功能检查，Linux ARM 通过 110 项完整离线回归；另通过 computer use 检查 F8/F9 开关、加粗与撤销，以及原生菜单条目操作。快捷键列以实际 NSMenuItem / GtkAccelLabel 数据核验；AX 菜单查询不作为菜单展开的实拍证据。记录保存在忽略的 `release/verification/menu-shortcuts/`。

侧栏查找入口按新提供的 Windows 截图调整，增加两项功能回归，最终 macOS ARM 打包版通过 28 项离线功能检查，Linux ARM 通过 112 项完整离线回归。检查新配置默认摘要列表、顶部/标签栏滚动入口、保留普通列表滚动、Esc 和键盘标签切换、三个真实搜索开关、选项留白、过期结果及窄宽布局。Computer use 实际执行标签栏向下滚动、查询输入、Tab/Space 切换开关及 Esc；大小写、整词和正则分别改变真实文件匹配，文稿保持原样。真实滚轮触发后采到 20 帧，其中 10 帧处于展开中间高度。选项面板外观以键盘聚焦实拍核对，不将工具的指针点击当作原生悬停证据。记录保存在忽略的 `release/verification/sidebar-search/`。

继续对照实际编辑：在本机 Typora 的临时文稿中执行列表 Tab/Shift+Tab、空列表/嵌套引用的连续回车、引用开头退格，以及查找框全选和撤销；切换源码模式读取结果。由此修复列表正文内 Tab 错插空格、退出空项缺少段落分隔或父级缩进、嵌套引用退格以及查找框快捷键差异，并补齐父列表续段的原生文字渲染。继续实测同项文字选区回车、非空列表项开头退格，以及首项取消列表后的子项提升；对应修复正反向选区续项、Tab 分隔标记、前同级/父项续段、首项子树缩进和无缩进空行渲染异常。列表转换仅补必要段落边界并沿用原缩进，不为模拟 Typora 的全表序列化而重排无关项；复杂跨块选区与含富内容的嵌套列表仍未完整对齐。编辑和功能回归覆盖任务/有序列表、子项与续行、反向选区、下一行边界、原有缩进、单步撤销、源码/代码缩进及输入框焦点，同时收集 CodeMirror 内部处理异常。最终 macOS ARM 打包版与 Linux ARM 各通过 121 项完整离线检查；打包版还通过实际按键的选区回车、子项退格、首项子项提升和两项单步撤销核验。测试框架先将焦点从编辑回归 iframe 交回主文档，再删除框架，避免 WebKit 的 CSS 焦点状态干扰后续侧栏检查。验证结果与本轮实际键盘记录保存在忽略的 `release/verification/list-parity/`，此前记录保存在 `release/verification/editing-details/`。此前查找框重做的即时界面结果正确，但随后窗口收到额外复制粘贴按键，最终状态记录受到干扰，未计入稳定断言；保留了当时内容与窗口。输入法组合保护使用事件回归检查，未据此宣称覆盖全部真实输入法。

界面语言覆盖原生菜单、七个偏好设置页面、主界面、侧栏、代码与表格工具、拼写语言名称、提示、对话框和辅助功能标签；Markdown、LaTeX、产品与代码语言名称，以及文稿、路径和用户输入保留原样。语言切换原位更新设置控件与已打开的应用对话框，保留搜索、未提交文本、选区、滚动位置和文稿撤销历史。README 和使用指南、迁移、隐私、组件说明提供中英文版本，并在开头互链。系统文件选择器、打印面板和系统服务的内部文字仍遵循操作系统语言。
