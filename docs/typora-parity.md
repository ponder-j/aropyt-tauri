# 功能状态与 Typora 差异

> 本文保留原项目的功能细节与已知 Typora 差异。文末的 Electron 历史验证记录不代表本次 Tauri 验证；Tauri 迁移和实际检查结果以 [迁移核对](migration.md) 为准。

更新日期：2026-10-22。本文描述当前源码已实现的行为；Aropyt 尚未 1:1 复刻 Typora。“已实现”“已确认差异”和“尚未验证”分别列出，避免把菜单存在或设置能够保存当作功能已完成。

## 对照基准

- 编辑交互主要对照本机 **macOS Typora 1.9.4** 的实际操作及保存后的 Markdown。
- 底栏、统计与拼写面板、正文右键菜单同时采用用户提供的 **Windows Typora 1.9.5 / 新版截图及分析文档**。这些界面与本机 Mac 版不同：Aropyt 的正文菜单采用参考中的 DOM 图标行，本机 Mac Typora 使用系统菜单；底栏也采用用户指定的新版布局。
- 官方帮助用于发现检查项，不作为本机行为已经一致的证据。不同平台和版本的结果不能直接互相替代。

## 已实现

| 范围 | 当前行为 |
| --- | --- |
| 标题与段落 | ATX 标题隐藏 `#`，点击保持字号和间距，开头 Backspace 取消格式；单行 Setext 标题隐藏下划线。Enter 创建段落，Shift+Enter 保留段内换行；段落合并、额外空段落及撤销有检查。 |
| 行内编辑 | 常见段落中的加粗、斜体、行内代码和链接只展开光标所在片段；保留相邻格式、嵌套及转义。支持行、句、格式文本和词的选择/删除。 |
| 代码框 | 围栏隐藏，正文直接编辑；支持方向键、缩进、空框、未闭合围栏、代码高亮、行号及撤销。右下角语言候选含字体图标和别名，聚焦不挤动下方排版，输入与正文事件隔离。 |
| Mermaid | 点击图形展开上方代码框，下方保留实时图形；有效修改后更新图形，离开后收起代码框。语言外框包含在预览区域内；导出等待 SVG 渲染完成。 |
| 数学 | 行内和表格公式点击后选中 TeX 并显示浮动预览，离开后恢复图形，保留邻近格式。支持公式块及 `math` 围栏、TeX/MathML 复制和 SVG/PNG 保存。 |
| 列表与任务 | 简单引用、列表和嵌套文字项保持结构；Enter 续写编号、引用或未完成任务，空项退出；Shift+Enter 创建不带新圆点的续行；任务勾选可以撤销。 |
| 表格 | 输入表头后 Enter 建表；单元格直接编辑，局部展开行内格式及公式。支持 Tab/Enter 导航、尺寸网格与数字输入、行列增删/移动、对齐、复制、整理、TSV 粘贴和统一撤销。 |
| 独立图片 | 编辑 Markdown 或 HTML 时保留预览；加载失败时显示可编辑源文。支持尺寸属性、25/33/50/67/80/100/150/200% 缩放、语法转换、打开位置、复制/移动文件、复制图片内容及上传入口。 |
| 正文右键菜单 | 剪贴板四图标、两行格式按钮、动态块类型、插入及内容专用子菜单；右键保留选区，支持子菜单翻转、视口限制、键盘导航与禁用状态。代码命令只在源码区出现；源码模式仅显示剪切/复制/粘贴。 |
| 底栏与统计 | 按新版参考显示侧栏/源码按钮、悬停出现的 A✓、可点击统计面板。展开侧栏后按钮跟随编辑区，源码模式覆盖侧栏按钮。统计原始 Markdown，包含代码、语言及地址；显示阅读时间、源文行数、UTF-16 字符数和选中/全部。 |
| 拼写 | 本地 Hunspell WASM 与 CLD2，36 个语言选项，可搜索、自动检测、关闭或按文稿选择语言；最多六个建议，按语言保存学习/取消学习。默认跳过代码和链接。 |
| 文件与视图 | 保存/另存为/移动、编码检测和换行符、自动草稿与恢复、未保存确认、文件树/平铺文件列表、大纲、查找替换、整词搜索、快速打开、焦点/打字机模式及 macOS 原生标签页。 |
| 主题与偏好 | 内置主题与自定义 CSS，补齐主题所需的 16 个字体文件；支持代码/列表缩进、智能标点、图像、图表、数学、导出、统计等设置，偏好可跨栏目搜索。 |

## 已确认未完全一致

| 范围 | 差异或限制 |
| --- | --- |
| 复杂内容的局部编辑 | 图片与正文混排、脚注引用、复杂 HTML、部分块级公式及复杂嵌套列表仍使用块级源文路径。含图片或复杂 HTML 的表格单元格尚未达到相同的局部编辑体验。 |
| 界面与平台集成 | 右键菜单和底栏采用上述 Windows/新版参考，不等同于 Mac Typora 的原生菜单和标题栏统计。语言候选集合、高亮、主题留白和字体细节仍有差异；偏好设置未完全中文化。 |
| 代码格式化 | 当前提供基础缩进调整，局部缩进会考虑整个代码块的层级；这不是覆盖每种语言的完整格式化器。 |
| 拼写与纠正 | 使用公开词典，未使用 Typora 的私有词典 fork；判词和建议顺序不能保证完全相同。语法纠正未复刻。中文、日文等语言模式按参考规则使用英语词典检查夹杂英文。 |
| 图片与图表 | 图片拖动缩放、引用式图片、混排媒体、表格边缘拖动重排及多种旧图表语法的兼容尚未完成。PicGo/PicList 和命令行上传入口已接入；iPic/uPic/Picsee 没有同等专用集成。 |
| 系统功能 | Typora 的原生文件版本历史、分享、最近文稿系统集成，以及系统替换、朗读、听写等完整菜单未全部实现。 |
| 发行 | 统一构建 Windows x64、macOS arm64 和 Linux x64 安装包，CI 汇总为单一发行草稿；签名及公证需要配置证书，尚无在线更新服务。见[构建与发布](releasing.md)。 |

## 尚未完整验证

这些项目不能标为“一致”，也不能仅因缺少检查就认定全部未实现：

- 多行 Setext 标题、复杂跨块选区与删除、完整嵌套列表项，以及所有语言的句子/词边界。
- 所有输入法、键盘布局和辅助功能选区；已有 Blink 到 CodeMirror 的选区同步检查，但未覆盖所有路径。
- 全屏、原生标签页、多屏、所有主题组合下的底栏、统计、菜单及窗口恢复。
- 大型文档性能、磁盘外部修改与冲突处理、全部数学扩展包、公式引用和连续编号。
- 真实第三方图床服务、视频和展开 emoji 的右键菜单分支；后两者已接入条件分支，尚无本机 Typora 实拍对照。
- GitHub Actions 发行工作流的实际执行、所有平台完整的安装/卸载及桌面集成验收，以及所有导出格式的逐页排版对照。Linux 已验证 Debian 12/X11 容器环境，Wayland 和其他发行版仍需检查。

## 导入导出

| 格式 | 已验证范围 | 验证边界 |
| --- | --- | --- |
| HTML / 无主题 HTML | 从完整文档生成，嵌入图片、字体、公式及 SVG 图形；重开不依赖文档脚本，保留 HTML 图片缩放尺寸。 | 不保证所有自定义主题及复杂 HTML 一致。 |
| PDF / PNG | 使用完成渲染的同一份文档；覆盖正在编辑的 Mermaid、源码模式、多个图形、公式、图片、文末及长图。PDF 曾渲染目视检查。 | 未逐像素对照全部文稿及纸张组合。 |
| 打印 | 共用完整导出文档，检查打印准备结果。 | 未向物理打印机发送任务。 |
| Word / ODT / Epub | 使用 Pandoc，检查真实归档结构。Word 包含原生表格、可编辑公式、嵌入图片、Mermaid 及 HTML 图片尺寸。 | 并非全部经过对应阅读器逐页目视检查。 |
| LaTeX / RTF / MediaWiki / rst / Textile / OPML | 生成实际文件；LaTeX 另外核对公式及持续可用的图形资源。 | 其余格式主要检查输出非空，不代表完整排版一致。文本格式的媒体资源需一同分享。 |
| Word 导入 | 真实 DOCX 经 Pandoc 转回 Markdown，核对正文及公式。 | 复杂 Office 文档结构未穷举。 |

Pandoc 是额外依赖，需在本机安装或配置路径。格式自身可表达的结构不同，例如 OPML 面向大纲；成功导出不等于与 Typora 排版相同。

| 命令 | 检查内容 |
| --- | --- |
| `npm run typecheck` | TypeScript 类型检查。 |
| `npm test` | 本机路径/URL 和启动参数、[统计算法](../tools/wordcount-test.mjs)的 13 组参考用例与边界，以及 [70 项编辑回归](../tests/editor.ts)。 |
| `npm run test:app` | 真实主进程、预加载和 Chromium 输入；含[右键菜单](../tests/context-menu-app.cjs)、[图片/表格](../tests/images-table-app.cjs)、[范围操作](../tests/ranges-app.cjs)及[底栏/统计/偏好](../tests/statistics-app.cjs)。 |
| `npm run test:features` | 真实剪贴板、文件与草稿、取消保存，以及 Pandoc 导入导出和输出结构。 |
| `npm run test:export` | 实际 HTML/PDF/PNG 导出动作、静态图形、字体与图片、长文档和打印准备。 |
| `npm run test:spelling` | 词典加载、英美差异、CLD2 检测与回退、建议、用户词典、归一及批次上限。 |
| `npm run test:packaged` | 实际打包应用的 ASAR/预加载、中文及特殊字符路径、字体、图片、MathJax、Mermaid、拼写、PDF 和保存。 |

本次跨平台改动已在 Windows x64、本机连接的 SSH macOS arm64，以及 Docker Linux x64 上通过当前检查，包括打包应用和 macOS DMG 挂载启动。环境与边界见[构建与发布](releasing.md#实际验证2026-10-22)。检查使用临时文件和隔离配置；涉及原生输入的检查需串行运行并避免焦点干扰。自动检查验证所覆盖的行为，不能替代未覆盖的功能、平台或视觉对照。

本机截图与临时对照文稿保留在被 Git 忽略的 `release/verification/`、`release/comparison/`，生成导出在 `output/`；这些目录不随仓库分发，也不作为阅读本文的前提。旧的逐轮检查日志已合并到本文，后续在相应功能行更新当前状态，不追加过时修复过程。
